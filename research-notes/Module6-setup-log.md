#### Which project you cloned
- I cloned the OWASP Nettacker GitHub repository (https://github.com/OWASP/Nettacker) and
deployed it inside a Kali Linux virtual machine using Git and the terminal in Visual Studio Code

#### Steps you followed


#### Commands you ran
- mkdir CSN190
- cd CSN190

- git clone https://github.com/OWASP/Nettacker
- cd Nettacker

- python3 -m venv venv
- source venv/bin/activate

-sudo apt install -y python3 python3-pip python3-venv git

- pip install -r requirements.txt
  
- python3 -m nettacker --help


#### Problems and solutions
- I created a Python virtual environment, activated it, and installed all required dependencies using pip. Initially, I encountered package installation issues due to repository configuration, but I resolved them by updating the system package list and verifying network
