#### Project Overview

- This project documents the deployment and practical use of OWASP Nettacker, an automated penetration testing and reconnaissance framework, within a Kali Linux virtual machine. The project focuses on setting up the tool from GitHub, resolving real dependency issues, executing a safe scan against a test target, and documenting the entire process through a tutorial and Medium-style article. The goal was to gain hands-on experience with real-world cybersecurity tooling and demonstrate troubleshooting, documentation, and communication skills.

#### Getting Started

#### To replicate this project:

- Set up a Kali Linux virtual machine with internet access

- Install Python 3, pip, venv, and git

- Clone the OWASP Nettacker repository from GitHub

- Create and activate a Python virtual environment

- Install missing dependencies as indicated by runtime errors

- Run Nettacker and execute a valid scan module against a safe test target (e.g., localhost)

- Detailed step-by-step instructions are provided in 6.3-TUTORIAL.md.

#### Results Summary

- This project successfully deployed OWASP Nettacker in a Kali Linux environment and executed a real scanning module with generated output. While the scan did not reveal major vulnerabilities (as expected when testing localhost), it confirmed that the tool was running correctly and producing structured results. More importantly, the project strengthened practical skills in Linux troubleshooting, Python dependency management, and tool documentation.

- Through this work, I learned that real cybersecurity tools often require persistence, careful reading of error messages, and an understanding of how software environments function. The experience reinforced the importance of documentation and communication, especially when explaining technical processes to others.
